Course Overview

Course: PIT201 – Data Warehousing

Programme/Department: Artificial Intelligence and Data Science (AI&DS), SRM VEC

Curriculum: R2023 · Teaching Plan: 45 periods (9 periods per unit)

Course Objectives

  • Understand data warehouse architecture.
  • Understand OLAP technology.
  • Understand partitioning strategies.
  • Differentiate data warehouse schemas.
  • Understand the roles of process managers and system managers.

Course Outcomes

By the end of this course, students will be able to:

  1. Design data warehouse architecture for given problems.
  2. Apply OLAP technology.
  3. Analyse partitioning strategies.
  4. Critically analyse suitable schemas for a given problem.
  5. Explain the roles of process managers and system managers.

Learning Resources

Prescribed Textbook

Alex Berson and Stephen J. Smith, Data Warehousing, Data Mining & OLAP, Tata McGraw Hill, 2017 reprint.

Dimensional Modelling

Ralph Kimball, The Data Warehouse Toolkit: The Complete Guide to Dimensional Modeling, 3rd edition, 2013.

Reference Book

Paul Raj Ponniah, Data Warehousing Fundamentals for IT Professionals, 2012.

Prepare unit-wise notes, practise OLAP operations, compare schemas, and design a small warehouse model using a real-world case.
